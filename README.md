# PLUTUS — Windows releases

This repository holds only the official PLUTUS Windows release packages:

- `PLUTUS-<version>-win64.zip` — the packaged application (`PLUTUS/PLUTUS.exe`, no Python required)
- `PLUTUS-release-manifest.json` — `PLUTUS_RELEASE_MANIFEST_V1` (version, asset size and SHA-256)

PLUTUS checks the Releases of this repository for updates. Each release states the certified source
commit and tag of the (private) source repository. No source code, data, credentials or personal
settings are published here.

本儲存庫僅提供 PLUTUS Windows 正式版安裝包與發行清單；PLUTUS 的自動更新只讀取本儲存庫的 Releases。
